Plug & play setup

Plugins are already loaded: Meyda (audio feature extraction) and Tone.js (playback).

Enable song identification

Get a token from AudD (audd.io), then paste it into CONFIG.apiToken at the top of the script. Host this file on your own site (the Claude preview host blocks calls to other domains). To use ACRCloud or another provider, replace the identify() function.

Accuracy

Browser analysis is an estimate. Dense mixes, alternate tunings and passing chords can confuse it, so always check by ear. Melody mode works best on solo, single-voice recordings.

Privacy

Audio files are decoded locally. Microphone audio is only sent out if you press Identify and a token is configured.
